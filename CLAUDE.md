# Writing style

- Never use em dashes (—) or en dashes (–), anywhere: code, docs, commit messages, PR descriptions, issue text. Use a comma, a period, or parentheses instead, whichever fits the sentence.
- Write in a direct, confident, human voice. No AI-typical filler ("furthermore", "it's important to note", "leverage", "seamless", "robust", "cutting-edge", "dive in", "unlock", "game-changer"), no perfectly balanced three-item lists, no repetitive "X does this, Y does that" sentence rhythm. Vary sentence length like a real person writing.
